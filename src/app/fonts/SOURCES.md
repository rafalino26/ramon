# Local fonts

The existing Geist and Coiny fonts are bundled locally through `next/font/local` to avoid network-dependent builds.

- [Geist variable font](https://github.com/google/fonts/tree/main/ofl/geist), copyright The Geist Project Authors, SIL Open Font License 1.1. License: `Geist-OFL.txt`.
- [Coiny regular](https://github.com/google/fonts/tree/main/ofl/coiny), copyright The Coiny Project Authors, SIL Open Font License 1.1. License: `Coiny-OFL.txt`.

Latin WOFF2 subsets downloaded from Google's Fonts API on 2026-11-04. The source URLs are retained in `font-sources.txt`; both files total approximately 45 KB. Original license texts are included alongside them.
